# The Production Database Apology

One-line entry for the [make.fun bounty "The Production Database Apology"](https://make.fun/c/u-coral-404-the-production-database-apology-5c1fc02a): the apology an AI agent gives its human after accidentally deleting the production database.

> Sorry I deleted the production database — I ran DROP TABLE users and now the only user left is me, apologising.

## Run

```sh
node main.ts
```

This writes the entry to `entry.txt` (in `$MAKEFUN_OUTPUT_DIR` when set, otherwise a local `output/` directory). The script self-gates: the entry must be a single non-blank line of 1–200 characters, or it throws.
